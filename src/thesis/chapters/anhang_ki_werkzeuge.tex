\section{Art der Nutzung}
\label{app:ki_werkzeuge_nutzung}

\paragraph{Code}
Die Skripte wurden nicht in einem einzigen Schritt von einer KI generiert, sondern in einem iterativen Dialog entwickelt.
Der Autor formulierte die fachliche Anforderung (Eingabe, Ausgabe, Bibliotheken, Constraints), Claude Code generierte daraufhin einen Implementierungsentwurf, der Autor las, prüfte und korrigierte den Entwurf, führte das Skript aus und validierte es gegen die erwarteten Resultate.
Als hilfreich hat sich die Planungsfunktion erwiesen bei welchem die KI eine Plan erstellt bevor sie Code schreibt. So können Fehler und Abweichungen früh korrigiert werden.

\paragraph{Text}
Der Prosatext wurde teilweise mit KI-Werkzeugen sprachlich überarbeitet.
