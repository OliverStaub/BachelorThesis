Website Fingerprinting - Dataset Example
========================================

Each sample is a sequence of packet directions captured
at the network level while a user visits a website through Tor.

  +1 = outgoing packet (client → Tor guard relay)
  -1 = incoming packet (Tor guard relay → client)
   0 = padding (no more packets in this visit)

Full dataset: 12000 samples, 80 website classes, 5000 values per sample
Split: 81% train, 9% validation, 10% test

The Deep Fingerprinting (DF) classifier learns to identify
which website produced a given direction sequence.

Example: the classifier sees only the +1/-1 pattern above
and predicts "this is website class 12" — without seeing
the actual content, URL, or any unencrypted data.
